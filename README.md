# Ремзона — демо-версия

Цифровой журнал ремонтной зоны карьерной техники: заезды и выезды машин, ремонт и ТО, «готова, ждёт не по нашей вине»,
выполненные работы для тех. отчёта, фото, сводка в рабочий чат, перенос в Excel-книгу, аналитика простоев.

**Это демо-версия.** Облачной базы нет — сервер имитируется прямо в браузере (`demo-backend.js`),
все машины, фамилии и записи вымышленные и хранятся только на устройстве того, кто открыл страницу.

## Как посмотреть

1. Откройте страницу (GitHub Pages) с телефона или компьютера.
2. Выберите учётную запись на экране входа, PIN — `1111`:
   - **Смирнов А.В.** — администратор: лента событий, площадка, люди, машины, **аналитика**;
   - **Иванов И.И.** и др. — механик: «Заезд машины», работы, готовность, выезд.
3. «Коллеги: вкл» — вымышленные механики время от времени делают записи, видно работу в реальном времени.
4. «Сбросить» — вернуть исходные данные.
